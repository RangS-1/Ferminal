Project Generator

v1.4.3

Welcome to the Project Generator Section. In here, you will learn how to use Ferminal to create new projects quickly.

Prerequisites

sudo pacman -S --needed base base-devel git

Commands

Here are the Project Generator commands supported by Ferminal, grouped by purpose:

Update

nm                 # Update available project templates

Generate Projects from RRC Repository

nm py              # Generate a new Python project (./basic_app)
nm blog            # Generate a new Blog project (./blog)
nm doc             # Generate a new Documentation project (./documentation)
nm love2d          # Generate a new Love2D project (./love2d_app)
nm react           # Generate a new React project (./react_app)

Generate Projects from others

nm lrv<version>    # Generate a new Laravel project
